# مطابقة عمليات Laravel وتطبيق الموبايل

آخر تحديث: 2026-10-26.

الحصر يقارن النماذج والإجراءات والفلاتر والعلاقات في app/Filament مع routes/api.php وشاشات Flutter الفعلية. وجود شاشة أو مسار وحده لا يثبت نجاح العملية على جهاز. دليل التحقق: docs/v2/qa/MOBILE_WEB_PARITY_2026-10-26.md. عقد API: docs/V2_S1_HANDOVER.md القسم 6.

## تصحيح التقرير السابق

نقل ملكية العداد والاستعادة والحذف النهائي الجماعي للتعرفة موجودة بالفعل في الكود الحالي؛ وصفها بأنها معطلة أو مفقودة في تقرير 2026-10-23 قديم. لا نضيف نسخة ثانية. API يتحقق من الصلاحية والمشترك وتفرّد المسار في المربع، لكنه لا ينقل الفواتير والسندات التاريخية إلى المالك الجديد. سلامة الأثر المحاسبي لهذه العملية تحتاج قبولًا مستقلًا.

ظهرت نواقص لم يذكرها الجدول السابق: مراجعة صناديق المحصلين، سجل التدقيق المركزي، حقول تعديل الطلبات والرسوم، حارس الدور، حفظ تصميم فاتورة الاشتراك، وقوائم تقرأ الصفحة الأولى فقط.

## تغييرات الربط والحماية

- مراجعة الصندوق تحمل بيانات حديثة قبل القرار وتمنع الإرسال المتكرر وتحتفظ بسبب الرفض عند الخطأ. الخادم يقفل السجل ويقبل القرار للجلسة المغلقة المعلقة فقط؛ النسخة القديمة لا تكتب فوق قرار سابق.
- خيارات الفاعلين والمحصلين تأتي من المسار المسموح نفسه دون اشتراط إدارة المستخدمين. سجل التدقيق يعرض القيم قبل/بعد وهوية الفاعل.
- فشل خطوة لاحقة أو إلغاؤها في إنشاء المشترك/العداد/الرسوم لا يعيد إنشاء السجلات السابقة.
- واجهة الدور تدعم العرض دون التعديل. API يتحقق من الحراس المكوّنين ويرفض صلاحيات حارس آخر وتغيير حارس دور مستخدم بالفعل.
- صلاحية تصميم الفاتورة/السند ترفع صوره المحددة دون منح تعديل مفاتيح إعدادات أخرى.
- فشل حذف سند لا يزيل العنصر من الواجهة على أنه نجاح.

## القوائم الكبيرة وخيارات العرض

عقد sort_by وsort_direction متاح في قوائم API بقوائم حقول مسموحة فقط. الفرز يحدث قبل paginate مع id ثابت للقيم المتساوية. الحقل أو الاتجاه غير المسموح يرجع 422. يشمل العلاقات وأعداد السجلات ومجموع الفاتورة مع الرصيد السابق. الحقول في ApiController::LIST_SORTS.

القوائم التي تفرز محليًا تجمع صفحات Laravel أولًا. المجمّع يطلب أرقام الصفحات عبر العميل الموثق ولا يتبع روابط next_page_url إلى خادم آخر، ويرفض التكرار الكامل والصفحات الفارغة قبل النهاية وفشل صفحة لاحقة بدل عرض نجاح ناقص. القوائم المالية التي تحتفظ بترقيم الخادم تستخدم بياناته الفعلية وتسمّي مجاميع الصفحة بوضوح.

خيارات العرض المشتركة تشمل الفرز واتجاهه وحجم الصفحة والعرض المضغوط وإظهار الحقول الثانوية. هوية السجل وأزراره الأساسية تبقى متاحة. الكاش القديم للعدادات لا يحتوي تاريخ إنشاء العداد؛ عند غيابه يحتفظ ترتيب هذا الحقل باستقرار السجلات، دون اختراع تاريخ.

## حدود التحقق

يلزم قبول على أجهزة Android/Windows وحسابات مدير ومحصّل وقارئ وعرض مخصص ضد خادم الاختبار، مع تغيير الصلاحيات أثناء الجلسة. الطباعة الحرارية والكاميرا والمشاركة وواتساب وتجربة الانقطاع على جهاز فعلي لا تثبتها اختبارات الودجات. تحقق أثر نقل الملكية يكون ببيانات اختبار ومطابقة كشف الحساب.

هذه المراجعة ليست شهادة إطلاق إنتاجي أو دليلًا على تنفيذ كل إجراء يدويًا على جهاز.
