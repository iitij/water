# سياسة الخصوصية وأجوبة قسم Data safety — Google Play

> آخر تحديث للنص: 2026-10-24. هذه وثيقة إعداد للنشر، وتحتاج مراجعة قانونية
> نهائية باسم الجهة المالكة قبل الرفع.

## 1. من نحن وما البيانات التي نعالجها

نظام إدارة المياه يعالجه مكتب إدارة المياه (الجهة المالكة). التطبيق أداة عمل
داخلية للموظفين والقراء، وليس خدمة موجّهة للجمهور العام.

| النوع | أمثلة | الغرض | أين يُخزَّن |
| — | — | — | — |
| بيانات هوية مهنية | اسم الموظف، البريد، الدور | تسجيل الدخول والصلاحيات | خادم الجهة |
| بيانات مشتركين | الاسم، الهاتف، العنوان، المربع | فوترة وتحصيل وتذكير | خادم الجهة |
| بيانات العدادات والقراءات | كود العداد، الاستهلاك، التواريخ | الاحتساب والفوترة | خادم الجهة + الجهاز |
| بيانات مالية | فواتير، سندات، مبالغ، طريقة الدفع | التحصيل والمطابقة | خادم الجهة + الجهاز |
| بيانات جهاز | معرّف عشوائي، المنصّة، إصدار التطبيق | إبطال جهاز مفقود ودعم | خادم الجهة |
| سجلات تدقيق | من فعل ماذا ومتى | المساءلة | خادم الجهة |
| أخطاء تقنية | رمز الحالة، اسم العملية | الإصلاح | الجهاز (نص فقط، بلا محتوى بيانات) |

**لا نجمع:** الموقع الجغرافي، جهات الاتصال، الرسائل، الصور الشخصية، سجل
التصفّح، معرّفات الإعلانات. لا إعلانات ولا تحليلات تسويقية ولا بيع بيانات.

## 2. الأساس والأمان

- نقل البيانات بـHTTPS فقط (التطبيق يرفض HTTP في الإنتاج).
- كل طلب يحتاج توكناً صادراً لتسجيل الدخول، ويُرفض في أول طلب بعد إبطال الجهاز.
- قاعدة الجهاز المحلية (Drift/SQLite) تُشفَّر بـSQLCipher عند تفعيل
  `ENCRYPT_LOCAL_DB=true`، والمفتاح في `flutter_secure_storage`.
- كلمات المرور لا تُخزَّن على الجهاز؛ التوكِن في التخزين الآمن.
- الصلاحيات على الخادم لا في الواجهة: كل مسار API يتحقق من صلاحية مستقلة.

## 3. الاحتفاظ والحذف

| البيانات | مدة الاحتفاظ |
| — | — |
| سندات وفواتير | حسب اللوائح المالية للجهة (لا تُحذف من التطبيق) |
| سجلات تدقيق | 12 شهراً على الأقل |
| بيانات محلية على الجهاز | حتى تسجيل الخروج أو حذف التطبيق |
| نسخ احتياطية محلية | يحذفها المستخدم من الشاشة |
| سجلات أخطاء محلية | آخر 50 خطأً تُدوَّر تلقائياً |

طلب صاحب البيانات (مشترك) يُقدَّم إلى الجهة المالكة، ويُنفَّذ من لوحة الإدارة
وفق اللوائح. الحذف النهائي متاح للمشرف ضمن صلاحياته وبسجل تدقيق.

## 4. مشاركة البيانات

لا تُشارك البيانات مع طرف ثالث إلا:

1. خادم الجهة المالكة (استضافة داخلية أو سحابية متعاقدة).
2. خدمة واتساب لتنفيذ إرسال يطلبه المستخدم صراحةً (يُرسل رقم المشترك والرسالة).
3. فلاتر الطباعة/المشاركة على الجهاز حين يطلب المستخدم مشاركة ملف (CSV/PDF).

## 5. أجوبة قسم Data safety في Play Console

| السؤال | الجواب |
| — | — |
| هل يجمع التطبيق بيانات أو يشاركها؟ | نعم — يجمع (لا يشارك للبيع) |
| هل البيانات مشفّرة أثناء النقل؟ | نعم |
| هل يمكن للمستخدم طلب حذف بياناته؟ | نعم — عبر الجهة المالكة |
| أنواع البيانات المجموعة | معلومات شخصية (الاسم)، معلومات مالية (المدفوعات)، معلومات الموقع؟ **لا**، جهات الاتصال؟ **لا** |
| الغرض | وظائف التطبيق (App functionality) وإدارة الحساب |
| هل التطبيق موجّه للأطفال؟ | لا |

## 6. ملاحظات تدقيق ما قبل الرفع

- [ ] مراجعة بشرية للنص من الجهة المالكة.
- [ ] التأكد أن قائمة الحزم في `pubspec.yaml` لا تحتوي SDK إعلانات أو تحليلات.
- [ ] مطابقة نص السياسة داخل التطبيق مع هذه الوثيقة.
- [ ] رابط سياسة الخصوصية عام (URL) مطلوب في Play Console — **لم يُنشأ بعد**.
