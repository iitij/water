# خطة الدعم بعد الإطلاق — S6-06

> **الحالة:** الخطة معتمدة كوثيقة، لكن **لا يوجد فريق دعم مُسمّى ولا قناة
> مفعّلة** حتى الآن. بند «<24 ساعة» غير قابل للتحقق قبل تسمية أشخاص فعليين.

## 1. نطاق الدعم

أسبوعان بعد الإطلاق الإنتاجي (production)، يغطيان: القراء، المحصلين، المشرفين،
والمكتب (Windows).

## 2. القنوات

| القناة | الاستخدام | المالك |
| — | — | — |
| مجموعة واتساب للدعم | الأعطال اليومية السريعة | منسّق الدعم |
| رقم هاتف مباشر | عطل P1 فقط | مشرف التشغيل |
| بريد إلكتروني | تقارير الأعطال المكتوبة | الدعم الفني |
| تقرير الدعم داخل التطبيق | يُنسخ من شاشة التشخيص ويُرسل | المستخدم نفسه |

## 3. التزامات الاستجابة

| الدرجة | الاستجابة الأولى | الحل أو البديل | التصعيد |
| — | — | — | — |
| P1 (توقف/فقدان بيانات) | ≤ 1 ساعة | ≤ 24 ساعة أو بديل مؤقت | مطوّر فوراً |
| P2 | ≤ 4 ساعات عمل | ≤ 3 أيام عمل | قائد المنتج |
| P3 | ≤ يوم عمل | الإصدار التالي | — |
| استفسار استخدام | ≤ 4 ساعات عمل | فوري بالدليل | — |

الحد الأقصى المعلن للمستخدم: **أقل من 24 ساعة** لكل ما يُصنّف P1 أو P2.

## 4. الأدوار

| الدور | المسؤولية | البديل |
| — | — | — |
| منسّق الدعم | استقبال، تصنيف، متابعة | مشرف التشغيل |
| الدعم الفني | تشخيص عبر شاشة التشخيص والنسخ الاحتياطي | مطوّر |
| مطوّر مناوب | إصلاح P1 ونشر hotfix | — |
| مسؤول البيانات | استعادة نسخة، تصحيح قيود | المشرف المالي |

> يجب تسمية اسم واحد لكل خانة قبل الإطلاق. خطة بلا أسماء ليست خطة.

## 5. أدوات الدعم

- **شاشة التشخيص**: الإصدار، المنصّة، الخادم، طابور المزامنة، آخر الأخطاء
  (S5-06 + إضافة الإصدار في S9).
- **تقرير الدعم النصي**: زر «نسخ تقرير الدعم» — لا يُطلب من المستخدم كتابة أي تفاصيل.
- **النسخة الاحتياطية المحلية**: قبل أي إجراء تصحيحي على جهاز.
- **سجل التدقيق** على الخادم: من فعل ماذا ومتى.

## 6. سيناريوهات التشغيل الحرجة

| السيناريو | أول 10 دقائق | الحل |
| — | — | — |
| جهاز مفقود | إبطال الجهاز من حساب آخر | تدوير كلمة المرور، مراجعة التدقيق |
| قراءات لم تُزامن | مراقب المزامنة: هل هي «بانتظار» أم «فشل دائم»؟ | إعادة محاولة / تصدير النسخة الاحتياطية وإرسالها |
| فرق نقدي في الصندوق | لا تُعتمد الجلسة | مراجعة السندات الملغاة والطباعة المكرّرة |
| تطبيق لا يفتح بعد تحديث | تثبيت النسخة السابقة إن أمكن | استعادة نسخة احتياطية ثم تصعيد P1 |
| بطء شديد في القارئ | التحقق من حجم حزمة الأوفلاين | تقليل المربع، وتنظيف الذاكرة |

## 7. مؤشرات الأسبوعين

| المؤشر | الهدف |
| — | — |
| زمن الاستجابة الأولى (متوسط) | ≤ 4 ساعات |
| تذاكر P1 | ≤ 2، وكلها مغلقة ≤ 24 ساعة |
| نسبة التذاكر المحلولة بلا تصعيد | ≥ 70% |
| رضا المستخدم عن الدعم | ≥ 4/5 |

## 8. مراجعة ما بعد الأسبوعين

اجتماع واحد يُخرج ثلاثة قرارات مكتوبة: ما يُؤتمت، وما يُضاف للدليل، وما يُغلق
من ثغرات. تُحدَّث هذه الوثيقة بنتيجته.
