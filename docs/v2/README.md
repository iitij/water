# مصدر خطة الإصدار الثاني

هذا المجلد يولّد ستة ملفات المخرجات في `docs/`:

| الملف | الوصف |
| --- | --- |
| `../V2_MOBILE_PLAN_AR.pdf` | النسخة المطبوعة (A4، 65 صفحة، عربية RTL) — الملف الأساسي للعرض والاعتماد |
| `../V2_MOBILE_PLAN_AR.docx` | نسخة Word قابلة للتحرير والتعليق |
| `../V2_MOBILE_PLAN_AR.md` | نسخة Markdown للبحث والمراجعة داخل المستودع |

## البناء

```sh
python3 -m pip install fpdf2 uharfbuzz pypdfium2 python-docx
python3 docs/v2/build.py docs/V2_MOBILE_PLAN_AR.pdf
python3 docs/v2/build_md.py
python3 docs/v2/build_docx.py
```

## البنية

- `engine.py` — محرّك PDF صغير: A4، هوامش، ترويسة/تذييل، عناوين، فقرات، جداول
  RTL مرسومة يدوياً، صناديق تنبيه، وكتل كود. يستخدم خط IBM Plex Sans Arabic
  المضمّن في التطبيق نفسه، مع تشكيل HarfBuzz لربط الحروف العربية.
- `content_a.py` — الملخص التنفيذي والباب الأول (الحالة الراهنة، الأهداف).
- `content_b.py` — الباب الثاني (تجربة المستخدم، السيناريوهات، الوحدات).
- `content_c.py` — الباب الثالث (المعمارية، البيانات، الأمن، الخادم، الجودة، الإصدار).
- `content_d.py` — الباب الرابع والملاحق (الجدول، الفريق، الميزانية، المخاطر،
  القبول، الإطلاق، القرارات، الملاحق أ–هـ).
- `build*.py` — تُجمّع الكتل وتُصدر الصيغ الثلاث (PDF/MD/DOCX) مع فهرس بأرقام
  صفحات حقيقية (تمريرتان: الأولى لجمع الأرقام والثانية لطبعها).

المحتوى مكتوب مرة واحدة في `content_*.py`؛ لا تُحرَّر المخرجات يدوياً. أي تعديل
على النص يجب أن يقع في ملفات المحتوى ثم يُعاد البناء.

اقتراحات لأسلوب التحرير: استخدم `(“h1”, "…")` لفصل جديد بصفحة مستقلة، و`(“h2”, …)`
لقسم فرعي داخل الفصل، و`("table", headers, rows, widths, caption)` للجداول مع
مراعاة أن العمود الأول يُرسم يميناً (بداية السطر العربي).
