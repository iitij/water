# دليل المستخدم — نظام إدارة المياه 2.0

> النسخة العربية المختصرة. مقصودة للطباعة (A5) وللقراءة على الهاتف.
> **تنبيه صدق:** هذا الدليل يصف ما يفترض أن يعمل في الكود. بنوده لم تُختبر
> ميدانياً بعد؛ راجع `docs/v2/qa/DEVICE_MATRIX_AR.md` قبل توزيعه.

---

## 1. أول تشغيل

1. ثبّت التطبيق.
2. أدخل عنوان الخادم إن لم يكن مضبوطاً (`https://…`)، ثم «حفظ».
3. سجّل الدخول بالحساب الذي أنشأه المشرف لك.
4. اسمح بالكاميرا (للماسح) وبالإشعارات (للتذكيرات). رفض أحدهما لا يمنع العمل،
   لكنه يُلغي وظيفة.

## 2. القارئ الميداني

| الخطوة | الطريقة |
| — | — |
| تجهيز اليوم | «الميدان» ← «القارئ الميداني» ← تنزيل حزمة المربع (مرة، مع شبكة) |
| قراءة عداد | ابحث بالكود أو امسح الباركود ← أدخل القراءة ← «حفظ» |
| عداد مقلوب/معطّل | «لا يمكن قراءة العداد» ← اختر السبب ← يُسجّل للمشرف |
| متابعة الجولة | «وضع المسار» يعرض المحطة التالية ورقم المسار |
| انتهاء اليوم | «مراقب المزامنة»: يجب أن يكون الطابور صفراً قبل مغادرة المنطقة |

**قاعدة أساسية:** لا تحذف التطبيق قبل أن يصبح طابور المزامنة صفراً. إن اضطررت،
خذ نسخة احتياطية أولاً (القسم 6).

## 3. المحصّل

1. «المالية» ← «صندوق المحصّل» ← «فتح الصندوق» (مبلغ البداية).
2. «التحصيل السريع»: ابحث عن المشترك (أو امسح باركود العدّاد) ← المبلغ ← طريقة
   الدفع ← «إصدار سند».
3. «طباعة» أو «واتساب». نتيجة الواتساب تُسجّل على السند (أُرسل/فشل).
4. عند الإلغاء: «إلغاء السند» مع السبب — يبقى السند ظاهراً بحالة «ملغى».
5. نهاية اليوم: «إقفال الصندوق» ← أدخل العدّ النقدي الفعلي ← «إقفال».
   الفرق بين المتوقع والفعلي يظهر للمشرف قبل الاعتماد.
6. «تصدير سندات اليوم (CSV)» من شريط السندات: ملف يُفتح في Excel للمطابقة.

## 4. المشرف

| المهمة | المسار |
| — | — |
| متابعة اليوم | «لوحة التحكم» |
| اعتماد صندوق | «صندوق المحصّل» ← السند ← «اعتماد» |
| جودة البيانات | «جودة البيانات» ← راجع الحرجة أولاً ← اضغط المثال للانتقال |
| تصدير | «التصدير» ← مشتركون/فواتير/قراءات (Excel) |
| الأجهزة | «الملف الشخصي» ← «الأجهزة المسجّلة» ← أبطل المفقود |
| الصلاحيات | «الأدوار والصلاحيات» |
| الإعدادات | «استوديو الإعدادات» (الفاتورة، السند، الواتساب) |

## 5. التذكيرات

«المزيد» ← «تذكيرات الجهاز». أربعة تذكيرات مستقلة: قراءات صباحية، فواتير
ظهيرة، إقفال صندوق مساءً، ونسخة احتياطية أسبوعية (الجمعة افتراضياً). اضغط
الساعة لتغيير الوقت، وأرسل «إشعاراً تجريبياً» للتأكد.

## 6. النسخة الاحتياطية

«المزيد» ← «نسخة احتياطية محلية» ← «إنشاء نسخة الآن» ← «مشاركة» (Drive/واتساب).
الملف JSON يحمل بصمة تحقّق؛ الاستعادة ترفض أي ملف معدّل.

## 7. عند وجود مشكلة

«التشخيص والدعم» ← «نسخ تقرير الدعم» ← أرسله للمشرف. التقرير يحتوي الإصدار
ومنصّة الجهاز وحالة الطابور وآخر الأخطاء — لا يحتوي كلمات مرور.

## 8. الأفعال الممنوعة (حماية البيانات)

- لا تُشارك حسابك؛ كل عملية تُسجَّل باسمك.
- لا تُبطل جهازاً غير جهازك المفقود.
- لا تستعد نسخة احتياطية من جهاز آخر على جهازك أثناء العمل بلا إشراف المشرف.
- لا تفتح التطبيق على شبكة عامة مفتوحة بلا HTTPS.
