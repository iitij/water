# البحث والفلترة والترتيب — 2026-11-03

## السلوك

أدوات «خيارات عرض القائمة» تضيف البحث، والمسار الدقيق، والمربع، وفترة تاريخ
الإضافة عند انطباق الحقل على المورد. يوجد عداد للفلاتر ومسح مستقل وإعادة
الصفحة إلى البداية عند تغيير الفلاتر أو المصدر. يبقى ترتيب القيم المتساوية
ثابتاً، وتظهر القيم المفقودة في نهاية الترتيب التصاعدي والتنازلي.

المشترك متعدد العدادات يعرض جميع أرقام مساراته المميزة؛ التصفية تطابق أي رقم،
والترتيب يعتمد أصغر مسار رقمي. السجل المرتبط بعداد يعرض مسار ذلك العداد فقط،
والحساب العام يعرض مسارات المشترك. لا يُستبدل تاريخ الإضافة بتاريخ الاشتراك
أو الخدمة أو السداد. البيانات المفقودة تبقى مفقودة ولا تُختلق.

## التغطية

| القوائم | البحث/الترتيب | المربع/المسار | فترة الإضافة |
|---|---|---|---|
| المشتركون والعدادات والقراءات | أدوات مشتركة مع الفلاتر المتخصصة الأصلية | عرض وتصفية وبحث مركب | نعم |
| الفواتير والسندات | فرز وفلاتر عبر الخادم قبل الصفحات | هوية السجل + مسار دقيق + المربع الأصلي للفواتير | نعم |
| رسوم الاشتراك وطلبات الوايت والحركات | بحث وفرز بعد جمع كل الصفحات | عرض المربع والمسارات وتصفية مستقلة | نعم |
| ملف المشترك: العدادات والفواتير والمدفوعات والرسوم والطلبات وكشف الحساب | نفس الأدوات داخل قوائم Slivers حتى لا تزاحم الملخص على الجوال | الموقع من المشترك والعداد المرتبط | نعم عند وجود تاريخ حقيقي |
| المربعات والمستخدمون والأدوار والإعدادات العامة والأجهزة | بحث وفرز محلي كامل | لا تُعرض مسارات لموارد لا ترتبط بمشترك | نعم |
| التسعيرات ومراجعة الصناديق والتدقيق المركزي | الفرز والفلاتر المتخصصة الأصلية | بحسب معنى المورد الأصلي | فترة إضافة مستقلة عبر الخادم |
| طلبات إلغاء السندات | خيارات الفرز والتصفح + فلاتر الإضافة والمسار | هوية المربع والمسار في كل طلب | نعم |
| البحث الشامل | الفلاتر قبل حد النتائج لكل مجموعة | عرض الهوية والبحث بالمسار/المربع | نعم |

البحث الشامل يظل معاينة مختصرة بعدد محدود لكل مجموعة، مع إبقاء صلاحياتها.
الإجماليات خارج القوائم المحلية تبقى لإجمالي المصدر المحمّل؛ تظهر ملاحظة صريحة
عند تفعيل فلاتر العرض كي لا تُفهم كإجماليات جزئية للقائمة المفلترة.
