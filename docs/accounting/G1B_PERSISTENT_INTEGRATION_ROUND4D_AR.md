## 5. معاملة التكامل الدائم — تصميم API داخلي
Proposed names for future ownership, not files created: FinancialWriteCoordinator, FinancialPeriodRepository, FinancialCloseEvidenceBuilder, FinancialCloseApplicationService, FinancialClosedReportReader, FinancialCarryResolutionService. B sole shared owner until supervisor handback. No direct policy call from UI, API clients cannot pass gate_held/authorized/state_verified/coverage_verified or raw ledger sums. Coordinator is sole financial write entry facade (old services call only inside controlled unit). Read-only reporting and preflight may execute without gate but never publish certified result from live data.
- write(command): verify stable identity/request digest/role; outer transaction; acquire G1; read gate and authoritative state, replay existing command (exact + effects valid + current access), no write if replay; reject frozen/closed/missing period for new command; determine all relevant period/date/currency and lock L1–L5; revalidate evidence/roles/bounds, assertCanPost; reserve number L6 if applicable; apply financial document/legs/event registry/allocation/revision/audit/request result atomically; verify exact conservation; commit; return committed result. Lost response -> same command resolves existing result even after close, not duplicate. No time-of-check/time-of-use gap.
- freeze: gate first; lock period + command; require no other active freeze, end passed, predecessor/baseline verified, epoch/version headroom, previous committed writers included; pure freeze -> atomically save FROZEN, attempt and gate.active_freeze_attempt + epoch + version CAS, required audit and result; release DB lock at commit, retain persisted fence. Writers acquired before freeze commit included; later blocked with retryable business response/queue stays pending. No queued successful receipt or receipt number while fenced.
- prepare: gate first, verify matching freeze owner/epoch/version; gather complete source manifest from covered domains under persisted fence. If expensive, read-only keyset export in chunks with same stable freeze epoch, no writers; each page/manifest deterministic, verify at final prepare transaction. Record canonical prepared snapshot and proof counts + immutable evidence version/approval candidate; verify source checks (not merely boolean). No official report yet.
- approve: gate first, L1 and command, verify independent current actor permissions and separation from requester/preparer, current freeze epoch/version/predecessor, source manifest, hash and carry aging; reconstruct strict state and invoke pure approve; single txn insert closure/rows and report pointers, update state CLOSED (CAS), epoch release and clear active freeze, audit + committed command result; rollback any failure leaves FROZEN; never automatically reopen. Exact replay read-only with proof, no audit/number/closure duplicated. If response lost, query committed result. If failed audit/DB/retry, stay FROZEN until successful approve or independent abort.
- abort: gate first, FROZEN only, independent authority, reason + immutable attempt history, transition OPEN with epoch increment and release fence in same transaction + audit/result. No CLOSED->OPEN. If failed, keep FROZEN. Future watchdog alerts stuck attempt; no auto-release, no decrement/reuse epoch. Headroom check eliminates predictable terminal exhaustion.
- read closed: fetch immutable closure and canonical snapshot rows by period/format; verify hash chain/baseline/audit manifest; no live recompute or changing current names/roles/allocations; operational report clearly labelled provisional. Integrity failure => uncertified/unavailable, do not silently rebuild. 
- carry resolution: current open txn same gate; lock stable carry identity, verify source/remaining amount and no duplicate consumption; append resolution/current posting; carry-forward next closing snapshot shows original source + movements, prior closure unchanged. No carry merely to reconcile unexplained bank/cash difference; unresolved pending noncash claims are nonfinancial records only.
