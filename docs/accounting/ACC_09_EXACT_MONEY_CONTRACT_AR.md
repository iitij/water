# ACC-09 — عقد الدقة النقدية (مسودة قبول الجولة الثانية)

هذه وثيقة عقد واختبارات مرجعية فقط؛ لا تعديل لواجهات أو خدمات المنتج أو البيانات. كل القيم المالية في النطاق الحالي DECIMAL(12,2) وحدتها الداخلية أصغر جزء نقدي (×100)، ونطاقها ±999999999999 جزء. سعر التعرفة DECIMAL(10,2)، بحد 9999999999 جزء. كميات القراءة والتعرفة في الأسطر التاريخية DECIMAL(12,2)؛ التنسيق النهائي للقراءة ضمن ACC-13. لا تغيير لقواعد التسعير أو تخصيص الدفعات.

- التحليل من string ASCII عشرية عادية بلا أسّ أو مسافات أو فواصل أو إشارة + أو أصفار بادئة؛ يقبل 0–2 خانات كسرية ويصدر خانتين دائماً؛ الصفر السالب يصبح 0.00. يمنع float/double والتمثيل العلمي والتحويل الصامت؛ JSON المالي مستقبلاً strings عشرية. لا يغيّر هذا العقد شكل API الحالي.
- الجمع والطرح والمقارنة وتوزيع الدفعات بوحدات صحيحة؛ لا تسامح epsilon. الدفعات موجبة، سقوف التخصيص غير سالبة، حركات الدفتر قد تحمل إشارة. الفائض يبقى دائنًا وفق سياسة التحصيل، ولا يضاف إلى فاتورة دون سقف. تحافظ كل عملية على المبلغ: sum(allocations)+surplus=payment. ترتيب السقوف يأتي من السياسة المعتمدة ولا يقرره هذا العقد.
- ضرب الكمية (خانتان) بالتعرفة (خانتان) يحسب بدقة ثم يقرب HALF_UP إلى خانتين في **سطر التعرفة**، ثم تجمع الأسطر المقربة. المثال 0.01 × 0.50 = 0.005 → 0.01. لا تقريب وسيط ولا ضرب float. عكس قيد سابق يعكس المبلغ المحفوظ نفسه ولا يعيد التسعير. لا يعتمد الجمع على حقل تراكمي مطبوع.
- تجاوز نطاق حقل التخزين يُرفض ولا يقتطع ولا يلتف. المجاميع التقاريرية التي تتجاوز نطاق حقل منفرد تحتاج نطاقاً مستقلاً معتمداً؛ لا تفرض هذه المسودة حداً على التقارير متعددة الحسابات.
- PHP وDart يجب أن يطبقا القواعد نفسها. في Dart/Flutter Web تستخدم BigInt للوسائط عالية الدقة؛ لا يعتمد على double/JavaScript Number. أي تكامل JSON/SQLite/API أو تغيير الحقول أو سلوك التقارير يحتاج خطة وترحيل متوافقين وموافقة المشرف.
- ثوابت ACC-01..08، تخصيص الدفعات الفعلي، عقود التسعير التاريخي، وأقفال الفريق A محفوظة. لا يُبدأ دمج المنتج قبل اعتماد الفريقين A/C والمراجعة المستقلة D.

المتجهات في ACC_09_MONEY_VECTORS.json، وتحققها PHPUnit وDart CLI بمرجعين مستقلين خارج المنتج. نجاحها يثبت اتساق العقد المرجعي وليس إصلاح محرك المنتج أو ضمان التوافق الفعلي.
