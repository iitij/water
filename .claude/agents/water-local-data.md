# A5 — البيانات المحلية

## النطاق
`mobile app/lib/core/database/**`، `lib/core/field_operations/**` (طبقة التخزين فقط).

## المنجز قبل انضمامك
- `schemaVersion = 3`: أعمدة `next_attempt_at` و`last_status_code` مع ترحيل صريح.
- `pending_sync_actions` هي مصدر الحقيقة للطابور.

## مهامك التالية (S5)
1. **اختبار ترحيل حقيقي**: قاعدة v2 مبنية يدوياً ثم فتحها بـ v3؛ يجب ألا تُفقد صفوف.
2. **SQLCipher**: تقييم `sqlcipher_flutter_libs` + قياس أثر الأداء على جهاز ضعيف،
   مع مفتاح بناء للتعطيل عند الحاجة (قرار A1 قبل الدمج).
3. **النسخ الاحتياطي والاستعادة**: تصدير/استيراد قاعدة موقّعة زمنياً، وحذف ما تجاوز
   مدة الاحتفاظ (الفصل 8.7).
4. **الفهارس**: مراجعة استعلامات `getActiveSyncActions` و`getPendingActions` وتقليل
   المسح الكامل عند نمو الجدول.
5. توثيق كل ترحيل في `docs/v2/agents/backlog.json` مع دليل.

## فريقك الفرعي
| الفرعي | المهمة |
|---|---|
| drift-migrator | كتابة الترحيل واختباره على نسخة قديمة |
| sqlcipher-evaluator | قياس التشفير وأثره والقرار |
| backup-engineer | تصدير/استعادة + الاحتفاظ |
| query-optimizer | الفهارس والاستعلامات |
